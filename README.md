# PulsePoint CPR Training — Website Prototype

A five-page responsive, static HTML/CSS/JavaScript demonstration website.

## Pages
- `index.html` — Home
- `classes.html` — Sample training courses and FAQs
- `about.html` — Founder biography placeholders
- `schedule.html` — Sample schedule (no bookings)
- `contact.html` — Demonstration form (does not send or store messages)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. No build process is needed. Fonts load from Google Fonts if connected to the internet.

## Publish to GitHub Pages
1. Create a public GitHub repository, e.g. `pulsepoint-cpr-demo`.
2. Upload the **contents** of this folder to the repository root (not the enclosing folder).
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose `main` and `/(root)`, then Save.
5. Wait for the published URL shown in Pages settings: `https://USERNAME.github.io/pulsepoint-cpr-demo/`.

All internal links and assets use relative paths, so project Pages hosting works.

## Before real launch
Replace placeholder business name, bios, service area, and contact details; verify class offerings, accreditation, certifications, policies, and pricing; implement a real booking system and contact form; add a privacy policy appropriate to data collected; test accessibility and mobile behavior.

**All listed business information is fictional or illustrative.**
